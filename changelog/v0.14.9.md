Luvus v0.14.9 is a fork integration release. It adds sidebar search and text filtering from [#540](https://github.com/RizRiyz/luvus/pull/540), host-terminal theme following from [#541](https://github.com/RizRiyz/luvus/pull/541), and the remaining keyboard pane-menu fixes from [#532](https://github.com/RizRiyz/luvus/pull/532). Existing settings and snapshots remain compatible. The client protocol is now 25 because terminal-color reports include which ANSI palette slots the host actually answered. Restart running servers after upgrading so both server and clients use the new protocol.

## Improvements

- **Sidebar:** In WORKSPACES, AGENTS, FILES, and DIFF, `/` locates a visible row without hiding the others, and `\` filters out non-matching rows. FILES searches names and workspace-relative paths, including directories. DIFF shows the current `f` review state, and a missing stable selection fails closed instead of activating a shifted row.
- **Themes:** The `terminal` theme keeps its derived palette after a successful host probe, and falls back to terminal-native colors when the host does not answer. Optional dark/light theme following is off by default and does not overwrite the saved manual theme. Pane colors follow the host while preserving colors set by the child program.
- **Remote displays:** Host colors are applied only to the display that is becoming current. Background connections do not repaint the active surface, and switching back replays the latest cached host colors. A display that explicitly has no colors restores the terminal fallback.
- **Pane menu:** The keyboard pane menu is centered on its pane, and a hidden Move submenu no longer activates an undrawn destination.

## Known limitations

- Real-time DEC 2031 color-scheme notifications are not enabled. Host theme updates are discovered by the startup probe and when the terminal regains focus. Crossterm 0.29 still cannot deliver `CSI ?997` without a local patch, and this release does not add one.
- The client protocol changed from 24 to 25. Older clients and servers refuse the connection and ask for a restart; this release does not claim compatibility with protocol 24 after the palette-mask field was added.
- Upstream CI still reports existing Clippy findings in unchanged transport and Git test code, plus existing npm audit findings. Those are not fixed in this fork release.
- Kitty drawing remains limited to supported Unix thin clients. Physical Kitty-host visual verification and local Windows hardware testing have not been performed for this release.

This release is published from chuxubank/luvus develop. It does not merge the upstream pull requests.
