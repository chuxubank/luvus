Luvus v0.14.4 is a fork integration release. It combines the open pull requests below on top of upstream v0.14.3. Existing settings and sessions remain compatible; restart running servers after upgrading.

## Features

- **DIFF:** Optionally render native review diffs with Difftastic's structured alignment and token highlights while keeping Git patches and source-line comments ([#524](https://github.com/RizRiyz/luvus/pull/524)).
- **Keys:** Cycle to the next running agent or program-status pane with `Ctrl+Space '` ([#529](https://github.com/RizRiyz/luvus/pull/529)).

## Fixes

- **Input:** Ignore delayed terminal color replies so they cannot become pane keystrokes, including replies split by resize or Escape ([#525](https://github.com/RizRiyz/luvus/pull/525)).
- **DIFF:** Keep keyboard selection visible in long wrapped diffs and let the wheel reach the final row ([#526](https://github.com/RizRiyz/luvus/pull/526)).
- **DIFF:** Toggle a file back to unviewed, and keep that choice across shutdown and concurrent review reloads ([#527](https://github.com/RizRiyz/luvus/pull/527)).
- **Dependencies:** Update `pulldown-cmark` to 0.13.6 for RUSTSEC-2026-0433 and report browser-test startup failures instead of waiting out a silent timeout ([#528](https://github.com/RizRiyz/luvus/pull/528)).

This tag is published from `chuxubank/luvus` `develop`. It does not merge or release the upstream pull requests.
