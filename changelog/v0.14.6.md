Luvus v0.14.6 is a fork release that removes the Kitty graphics added in v0.14.5. Placeholder image cells shifted the pane layout while scrolling. Existing settings and sessions remain compatible. This build speaks client protocol 22 again, so restart running servers after upgrading.

## Fixes

- **Terminal:** Stop drawing Kitty graphics in panes. Images from v0.14.5 no longer appear, and scrolling no longer rearranges the surrounding text.

The keyboard pane menu, focused-pane cursor style, and DIFF fixes from v0.14.5 remain.

This tag is published from `chuxubank/luvus` `develop`. It does not include the separate direct-placement graphics work.
