Luvus v0.14.11 is a fork integration release. It brings the remaining review fixes from [#540](https://github.com/RizRiyz/luvus/pull/540) and [#541](https://github.com/RizRiyz/luvus/pull/541) after v0.14.10. The client protocol stays 25, so a v0.14.10 client and server can still connect. Restart is not required for a protocol change.

## Improvements

- **Sidebar:** Settings help for the AGENTS state shortcut now uses each language's own All/Active labels. Spanish, Portuguese, French, German, and Indonesian no longer leave the English words in that sentence.
- **Workspaces:** A theme change that arrives as a frame diff updates the client-owned WORKSPACES background on that frame. Popup cells and whole-frame dimmed backdrops, including Settings, are not saved as the dock background.
- **Input:** A split host color reply that begins with `ESC ]` stays held until its BEL or ST terminator. The palette body and its BEL are not typed into the focused pane.

## Known limitations

- A Luvus pane does not yet repaint when the outer terminal changes its palette without a focus change. Real-time DEC 2031 notifications remain disabled because Crossterm 0.29 cannot deliver `CSI ?997` without swallowing later input.
- A program that subscribes to DEC 2031, including Pi's `light/dark` theme, still depends on the outer terminal sending that notification. Current WezTerm builds do not. Ghostty does. Luvus does not add a polling color query.
- Kitty drawing remains limited to supported Unix thin clients. Physical Kitty-host visual verification and local Windows hardware testing have not been performed for this release.

This release is published from chuxubank/luvus develop. It does not merge the upstream pull requests.
