Luvus v0.14.5 is a fork integration release. It adds Kitty graphics, a keyboard pane menu, and the focused pane's cursor style on top of v0.14.4. Existing settings and sessions remain compatible. This build speaks client protocol 23, so restart running servers after upgrading.

## Features

- **Terminal:** Draw Kitty graphics in panes. Each pane keeps its own image ids, and closing a pane removes only those images.
- **Keys:** Open the focused pane menu with `Ctrl+Space` and then backtick, the key above Tab ([#532](https://github.com/RizRiyz/luvus/pull/532)). Pointer motion takes over a keyboard selection, and Enter runs the hovered row.
- **Terminal:** Match the host cursor to the focused pane's shape, blink, and color, including a blinking bar. A blink query no longer forces a steady block, and exiting Luvus restores the previous host cursor ([#538](https://github.com/RizRiyz/luvus/pull/538)).

## Fixes

- **DIFF:** Keep long wrapped reviews scrollable when rows, notes, and wide line numbers change height, including jumps after leaving Split for Stack ([#526](https://github.com/RizRiyz/luvus/pull/526)).
- **DIFF:** Keep a viewed or unviewed toggle across shutdown and concurrent review reloads ([#527](https://github.com/RizRiyz/luvus/pull/527)).

This tag is published from `chuxubank/luvus` `develop`. It does not merge or release the upstream pull requests.
